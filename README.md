Heart Disease Prediction Using Machine Learning ❤️🤖

This project predicts the possibility of heart disease in a patient using machine learning techniques. 
The model analyzes medical features such as age, gender, blood pressure, cholesterol level, chest pain type, 
fasting blood sugar, maximum heart rate, and other health parameters to classify whether a person is likely to have heart disease or not.

##The main objective of this project is to support early detection of heart disease
and help in making faster healthcare decisions. Different machine learning algorithms 
are trained and evaluated to find the best-performing model based on accuracy and other performance metrics.

Key Features

  Data preprocessing and cleaning
  Exploratory Data Analysis
  Feature selection
  Model training using Machine Learning algorithms
  Prediction of heart disease risk
  Accuracy and performance evaluation
  User-friendly prediction system

Technologies Used

  Python
  Pandas
  NumPy
  Matplotlib / Seaborn
  Scikit-learn
  Machine Learning

A machine learning project that predicts heart disease risk using patient medical data and classification algorithms.



The system predicts whether the patient has heart disease or not based on the given input features.
